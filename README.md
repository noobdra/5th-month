# For Bujjiiii — Our Little Universe

A mobile-first GitHub Pages site for the November 4 and November 8 releases.

## Files
- `index.html` — page structure
- `style.css` — responsive visual design
- `script.js` — room navigation and interactions
- `assets/first-home.png` — your original Minecraft screenshot

## Preview locally
Open `index.html` in a browser. For best results, use VS Code with the Live Server extension.

## Publish with GitHub Pages
1. Create a new public GitHub repository (for example `project-m`).
2. Upload the contents of this folder, keeping the `assets` folder.
3. Open repository Settings → Pages.
4. Set deployment source to Deploy from a branch, choose `main` and `/ (root)`.
5. Save and wait for the published URL.

## Before sending it to her
- Replace draft text in `script.js` with your final personal messages.
- Add recordings under an `audio` folder and update the Voice Vault section.
- Test on a phone and keep the link private/unlisted by not posting it publicly.
- The current version is a starter: the birthday expansion, real audio playback, and deeper house exploration still need to be added.
